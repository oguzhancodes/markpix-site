Perguntas Frequentes

O que o MarkPix faz exatamente?

O MarkPix é uma câmera profissional que carimba cada foto com localização (endereço + coordenadas), data/hora e dados meteorológicos opcionais. Ideal para relatórios de obras, avaliações de seguros, documentação imobiliária e provas legais.

Funciona offline?

Sim. Capturar fotos, obter coordenadas GPS e aplicar o carimbo funcionam offline. A Internet é necessária apenas para resolver o endereço (coordenada → endereço) e dados meteorológicos.

Como cancelo minha assinatura?

Assinaturas iOS são gerenciadas pelo seu ID Apple:

  • Ajustes do iPhone → seu nome → Assinaturas.
  • Selecione MarkPix → Cancelar assinatura.
  • Os recursos Pro permanecem ativos até o final do período.

Link direto: apps.apple.com/account/subscriptions

Posso obter reembolso?

Reembolsos são processados pela Apple: reportaproblem.apple.com. A Apple geralmente decide em 48 horas.

Minhas fotos são enviadas para seus servidores?

Não. O MarkPix não tem servidores. Todas as fotos e dados de localização permanecem no seu dispositivo. Apenas as coordenadas são enviadas à Apple para resolução de endereço — suas fotos nunca saem do dispositivo.

O GPS não funciona — o que fazer?
  • Saia para o ambiente externo (GPS é fraco em ambientes internos).
  • Ajustes → Privacidade → Serviços de Localização ativado.
  • Ajustes → MarkPix → Localização em "Ao usar o app".
  • Reinicie o iPhone para redefinir o chip GPS.
